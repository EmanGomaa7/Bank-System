# 🏦 Rawnaq Bank

**Rawnaq Bank** is a C++ Bank Management System designed to simulate a simple and organized banking environment.

The project focuses on applying **Object-Oriented Programming (OOP)** concepts and building a structured system for managing banking data and operations.

It was developed as a collaborative project to practice and demonstrate practical **C++ programming, OOP, data validation, and file handling**.

### 🛠️ Built With

* C++
* Object-Oriented Programming (OOP)
* File Handling
* Data Validation
